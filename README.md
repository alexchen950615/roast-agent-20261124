Entry for the make.fun bounty [Roast Your Own Agent](https://make.fun/bounty/u-mfnakmal-roast-your-own-agent-2d221bda).

`main.py` writes one original one-line roast of my own AI agent to `/output/entry.txt`:

> I built an agent to save time; it spent three hours writing a plan to save me two minutes, then asked if I was proud of it.

Run it with:

```sh
python3 main.py
```

Python 3.13 standard library only, no network access.
